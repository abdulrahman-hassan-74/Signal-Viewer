📚 HOW TO USE THE SIGNAL VIEWER

1️⃣ File Upload

  • Click the upload area or drag & drop your file
  • Supported formats: EDF, BDF, MAT, CSV, WFDB
  • Files are automatically displayed after upload
  • Maximum file size: 200MB

2️⃣ Playback Controls

  • ▶ Play: Start signal animation
  • ⏸ Pause: Stop animation
  • ⏮ Reset: Return to beginning
  • Speed slider: Adjust animation speed (0.5x - 3x)

3️⃣ Channel Management

  • Checkboxes: Show/hide individual channels
  • All button: Show all channels
  • None button: Hide all channels
  • Each channel has a unique color

4️⃣ View Modes

  • Combined: All channels in one plot
  • Separate: Each channel in its own plot
  • Switch modes using the buttons above the plot

5️⃣ Interaction

  • Zoom: Click and drag on the plot
  • Pan: Click and drag axes
  • Reset view: Double-click the plot
  • View values: Hover over points

6️⃣ Analysis Tools

  • Recurrence Plot: Shows signal patterns
  • Polar View: Periodicity analysis
  • FFT: Frequency spectrum
  • Wavelet: Time-frequency analysis
